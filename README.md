# Lumen 1.2 — test

Тестовая ветка Lumen: только исходный код и минимальные файлы для запуска.
Без скриншотов, релизных артефактов и готового `.exe`.

Lumen — спокойный браузер на Electron 45 / Chromium с полностью кастомным
редактором интерфейса. Чистый JavaScript и CSS, без React и сборщика.

## Запуск

```bash
npm install
npm start
```

Требуется Node.js 22.12+.

## Сборка

```bash
npm run dist
```

Windows portable-версия появится в `dist/Lumen-1.2.0-portable.exe`.

## Что внутри

- настоящие вкладки на `WebContentsView`;
- новая вкладка, закладки, история, загрузки и восстановление сессии;
- command palette (`Ctrl K`);
- редактор интерфейса: темы, любые HEX-цвета, радиусы, плотность, шрифты,
  фактуры фона и свечение;
- Chrome, Яндекс и DuckDuckGo как поисковики;
- данные хранятся только локально.

## Ветки

| Ветка | Содержимое |
| --- | --- |
| `main` | Полная версия с оформленным README и скриншотами |
| `test` | Только исходный код для тестов и сборки |
