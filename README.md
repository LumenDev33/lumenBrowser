# Lumen

**Lumen** — спокойный браузер на Chromium с собственным интерфейсом, тёплой типографикой и продуманными деталями. Он не пытается быть ещё одной копией Chrome: меньше шума, больше пространства и многоцветная палитра, которая делает интерфейс своим. Светлая, тёмная или системная тема — на выбор.

**Версия 1.1:** новая чёрно-фиолетовая иконка, темы оформления, редактируемое имя в приветствии и поисковики Chrome, Яндекс, DuckDuckGo.

![Lumen](preview.png)

## Запуск

```bash
npm install
npm start
```

Или напрямую через Electron:

```bash
npx electron .
```

Требуется Node.js 22.12+ и установленный Electron. Приложение использует Electron 45, чистый JavaScript и CSS — без React и сборщика.

## Что умеет

- **Вкладки на Chromium.** Каждая страница живёт в отдельном `WebContentsView`, поэтому сайты работают по-настоящему: JavaScript, видео, формы, авторизация.
- **Новая вкладка как тихое пространство.** Поиск, быстрый доступ к закладкам и недавняя история — без визуального шума.
- **Свои закладки.** Звезда в адресной строке, быстрые карточки на стартовой странице и блок в сайдбаре.
- **История.** Поиск, группировка по дням, удаление отдельных записей и полная очистка.
- **Загрузки.** Прогресс, размер, открытие файла и показ в папке.
- **Command palette.** `Ctrl K` — единое место для команд, поиска по истории и закладкам.
- **Настройки.** Имя для приветствия, поисковик (Chrome, Яндекс, DuckDuckGo), тема (тёмная, светлая, системная), акцентный цвет (золото, мята, небо, коралл), видимость закладок и анимации.
- **Личное приветствие.** Если имя не задано, Lumen просто здоровается без обращения. Имя можно изменить или очистить в настройках в любой момент.
- **Сессия.** Lumen запоминает открытые вкладки и восстанавливает их при следующем запуске.
- **Ссылки и новые окна.** `target="_blank"` и `window.open` открываются как вкладки; `mailto:` и `tel:` передаются системе.
- **Контекстное меню.** Открыть ссылку в новой вкладке, скопировать, назад/вперёд, обновить, DevTools.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| `Ctrl T` | Новая вкладка |
| `Ctrl W` | Закрыть вкладку |
| `Ctrl Shift T` | Вернуть закрытую вкладку |
| `Ctrl Tab` / `Ctrl Shift Tab` | Переключение вкладок |
| `Ctrl L` | Фокус в адресную строку |
| `Ctrl K` | Command palette |
| `Ctrl H` | История |
| `Ctrl D` | Добавить/убрать закладку |
| `Ctrl ,` | Настройки |
| `Ctrl R` / `F5` | Обновить |
| `Alt ←` / `Alt →` | Назад / вперёд |
| `Ctrl +` / `Ctrl -` / `Ctrl 0` | Масштаб |
| `F12` | DevTools страницы |

## Структура

```
lumen-browser/
├─ src/
│  ├─ main.js          # окно, вкладки, WebContentsView, IPC, хранение
│  ├─ preload.js       # безопасный window.lumen
│  └─ ui/
│     ├─ index.html    # разметка и SVG-иконки
│     ├─ styles.css    # дизайн-система
│     └─ app.js        # логика интерфейса и демо-режим для Chrome
├─ assets/
│  ├─ icon.svg
│  └─ icon.png
└─ package.json
```

## Данные

Состояние хранится локально:

```
<app.getPath("userData")>/lumen-state.json
```

В нём настройки, закладки, история, загрузки и последняя сессия. Загруженные файлы сохраняются в системную папку «Загрузки».

## Разработка

```bash
npm run dev
```

Интерфейс можно открыть и в обычном Chrome — `src/ui/index.html` умеет работать в демо-режиме без Electron. В этом случае используются тестовые вкладки и данные.

## Примечания

- Запросы разрешений сайтов (геолокация, уведомления, камера) по умолчанию отклоняются — это осознанное решение для спокойного и безопасного браузера.
- Движок страниц — Chromium из состава Electron. Обновление Electron обновляет и Chromium.
- Интерфейс адаптирован под минимальное окно 1024 × 680.

---

Сделано как маленький, личный браузер: без лишних панелей и без спешки.
