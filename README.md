# Lumen 2.0 Beta — test

Тестовая ветка Lumen: только исходный код и минимальные файлы для запуска.
Без скриншотов, концепт-арта, релизных артефактов и готового `.exe`.

Lumen — спокойный браузер на Electron 45 / Chromium с полностью кастомным
редактором интерфейса. Чистый JavaScript и CSS, без React и сборщика.

Ветка содержит функциональность `2.0.0 Beta`: пространства, хронику сессий,
заметки, локальный щит и режим «Тишина».

## Запуск

```bash
npm install
npm start
```

Требуется Node.js 22.12+.

## Сборка

```bash
npm run dist
```

Windows portable-версия появится в `dist/Lumen-2.0.0-beta-portable.exe`.

## Что внутри

- настоящие вкладки на `WebContentsView`;
- новая вкладка, закладки, история, загрузки и восстановление сессии;
- пространства — именованные наборы вкладок без дублей;
- хроника — история, собранная в сессии по 30-минутным паузам;
- заметки к точному `http(s)`-адресу с автосохранением;
- локальный щит аналитических и рекламных подресурсов;
- режим «Тишина» на 25 минут;
- command palette (`Ctrl K`);
- редактор интерфейса: темы, любые HEX-цвета, радиусы, плотность, шрифты,
  фактуры фона и свечение;
- режим компоновки: перетаскивание и масштабирование любых элементов
  интерфейса с автосохранением раскладки;
- Chrome, Яндекс и DuckDuckGo как поисковики;
- данные хранятся только локально.

## Компоновка

**Редактор интерфейса → Компоновка → Открыть компоновку** или
«Компоновка интерфейса» в `Ctrl K`.

- тяните элемент мышью;
- тяните круглый маркер в правом нижнем углу для масштаба;
- `Alt` или кнопка «вложенные» выбирает внутренний элемент;
- `Shift` выравнивает по сетке 10 px;
- стрелки двигают выбранный элемент, `Delete` сбрасывает его;
- `Esc` или «Готово» выходит из режима.

Раскладка хранится в `settings.appearance.layout` и сохраняется автоматически.
